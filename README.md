# My Health Compass

Build the Medicore Smart Healthcare web app designed for mobile phones based on the attached UI design and presentation. Include the mobile screens from the design: splash screen ('Your Health, One Tap Away'), home screen ('Hello, Chloe F.' with categories like Check-up, Dental, Cardiology, and doctor cards), and doctor appointment booking with date and time slot selection and reason for visit. Include local doctors directory, nearby ambulances with location and contact, SOS emergency support, daily health checklist, vitals monitoring, and an AI symptom checker.
